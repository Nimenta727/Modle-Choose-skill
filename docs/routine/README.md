# 修改日志索引 / Change History

## 中文

本目录保留每次 GitHub 项目修改对应的时间戳记录、变更内容、实际验证和下一步规划。历史记录必须保留，过时的 CLI 命令与路径不应作为最新使用指南。请以 [当前文档索引](../README.md) 和 [主 README](../../README.md) 为准。

## English

This directory preserves a dated log for each GitHub modification, describing changes, actual checks and next steps. Historical paths and commands are archival rather than current usage instructions. Use the [documentation index](../README.md) and [main README](../../README.md) for supported paths.
