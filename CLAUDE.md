# Working on this repository

Before writing or revising a development plan, load `.claude/skills/model-router/SKILL.md` and its canonical instructions at `skills/model-router/SKILL.md`. Present the model-allocation section in the plan. This recommendation does not execute cross-provider calls.

After **every GitHub project modification**, write a dated change record in `docs/routine/` whose filename starts with `YYYY-MM-DD-HHMM-` (local timezone +08:00 unless stated otherwise). Include what changed, tests/checks performed, and next steps; commit it with the change. Never claim that a check passed without running it.
