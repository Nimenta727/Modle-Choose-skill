# Claude Code 仓库指令 / Claude Code Repository Instructions

## 中文

在创建或修改开发计划前，先读取 .claude/skills/model-router/SKILL.md 与 skills/model-router/SKILL.md；计划里展示模型主选/备用、实际可用性、模型目录日期和模型切换条件。读取 Skill 不代表取得跨厂商执行权限。

每次修改 GitHub 仓库都必须在同一提交新增 docs/routine/ 下带时间戳、内容简介的中英文变更记录，说明做了什么、实际跑过什么检查、还缺什么验证和下一步。不得伪称测试通过。

## English

Before revising implementation plans, read .claude/skills/model-router/SKILL.md and the canonical skills/model-router/SKILL.md. Report primary/backup models, real access confidence, catalog date and switch triggers. Reading a Skill does not authorize cross-provider execution.

For every GitHub modification, add a bilingual timestamped entry under docs/routine/ in the **same commit**, recording changes, checks actually performed, checks not run and next steps. Never claim unrun tests passed.
