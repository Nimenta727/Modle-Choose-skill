# 仓库 Agent 约定 / Repository Agent Instructions

## 中文

在创建或修改软件计划前，加载 .agents/skills/model-router/SKILL.md 与唯一完整技能 skills/model-router/SKILL.md；在计划中展示“模型分配 / Model allocation”、核实日期、可用性、备用方案和重路由条件。模型推荐不是执行许可，未经授权不得发起跨厂商调用。

每次 GitHub 项目修改都必须**在同一提交**新增 docs/routine/YYYY-MM-DD-HHMM-内容简介.md，记录中英文修改内容、实际运行过的检查、未执行的验证和下一步规划。禁止把未运行的测试声称通过。

## English

Before creating or revising a software plan, load .agents/skills/model-router/SKILL.md and the canonical skills/model-router/SKILL.md. Include Model allocation / 模型分配, verification date, access status, backup and rerouting conditions. Recommendation is not permission to execute or share data with another provider.

Every GitHub change must include a **same-commit** bilingual timestamped docs/routine/YYYY-MM-DD-HHMM-summary.md log with changes, observed checks, unperformed checks and next steps. Never claim a test passed unless it was actually run.
