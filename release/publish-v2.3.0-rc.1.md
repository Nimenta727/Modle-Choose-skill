# v2.3.0-rc.1 发布标记 / Release Publication Marker

## 中文

此提交明确触发 v2.3.0-rc.1 GitHub 预发布工作流。发布前重新运行离线单元测试、路由评测、双语链接预检和 Skill ZIP SHA-256 校验。发行资产仅包含独立 Skill，不包含用户数据或仓库执行器。

**限制：** 尚未在真实登录的 Claude Code/Codex 环境验证跨模型执行、Skill 自动触发率或 Token 节省幅度。项目许可证也尚未由版权持有人确认。

## English

This marker explicitly triggers the v2.3.0-rc.1 GitHub prerelease workflow. Publication requires offline unit and policy tests, bilingual link validation and a verified SHA-256 for the standalone Skill ZIP. No user data or host-side executor is packaged.

**Limitations:** Authenticated Claude Code/Codex cross-model execution, Skill activation rates and token savings remain unmeasured. The copyright owner has not yet approved a redistribution license.
